# 发散与收敛

一个想法细化不动，通常不是「不够深」，而是**选项空间太窄**。

先发散把空间打开，再收敛把空间关掉。**这两件事不要混在同一段里做**——一边生成一边评判，是创意枯竭的头号原因。

## 何时用 / 何时不要用

**用**：只有一条路可走；要在几个方案里选；纠结要不要做；创意枯竭；要给一堆选项排优先级。

**不要用**：选项已经清楚、只差执行；任务是例行的、没有真正的取舍；用户只是在两个差不多的选项之间挑，而你只想显得周全。

**停止信号**：新产出的想法开始只是已有想法的措辞变体；或者每个新角度都落在已经覆盖过的视角里——说明空间已经打开到位，该收敛了。

## 零、先做可逆性分类（决定类问题的第一刀）

比较选项之前，先给每个选项贴标签：

- **双向门**：做错了能低成本退回。→ 别过度分析，快点试，用最小代价换信息。
- **单向门**：退不回去，或代价很大。→ 值得把 pre-mortem、机会成本、二阶效应全走一遍。

很多「选不出来」，其实是在拿双向门做单向门的分析。分类做完，该快的那一半立刻快起来。

## 一、发散：先要数量，不要质量

规则：

1. **数量优先**——先凑够 8–12 条再评判。
2. **延迟评判**——生成阶段禁止出现「这个不行」。
3. **yes-and**——在已有想法上叠加，而不是替换掉它。
4. **至少 2 个疯狂想法**——它们常常是唯一能通向实用解法的那条路。
5. **约束反而提升创造力**——没有边界就没有方向，不要一上来就「什么都可以」。
6. **混入不同视角**——不同用户、不同角色、不同时间尺度。

技法（按需选 1–3 个就够，不要全上）：

- **SCAMPER**：替代 / 组合 / 适配 / 修改放大 / 挪作他用 / 消除 / 重排反转。
- **反向头脑风暴**：先问「怎样做才能保证这件事彻底失败」，列出失败清单，再逐条翻转为成功策略。用来暴露隐藏风险特别有效。
- **约束移除**：预算无限会怎么做？时间不是问题会怎么做？技术随便挑会怎么做？没有历史包袱会怎么做？——最后再问「哪些能缩回现实」。
- **组合杂交**：取 A/B/C 各自最强的部分，造 2–3 个杂交方案，而不是三选一。
- **视角轮换（六顶思考帽）**：事实 / 直觉 / 风险 / 收益 / 创造 / 过程，逐个视角过一遍。

## 二、收敛：用统一标准，而不是靠感觉

1. 先定标准，通常四项足够：**可行性、影响力、成本、风险**，各 1–5 分。
2. 做对比矩阵，逐项打分，给出总分与推荐。
3. 打分必须给出**依据**——「感觉 4 分」不算依据。
4. 说清**被淘汰的方案为什么被淘汰**。不写淘汰理由的推荐，等于没做评估。

## 三、四个固定拷问（收敛阶段的必答题）

- **Pre-mortem（事前验尸）**：假设这件事已经彻底失败，倒推——哪里出了问题？哪些预警被忽略了？哪个假设被证伪了？现在能做什么阻止它？
- **二阶效应**：第一层之后会发生什么？谁会因此改变行为？出现什么意外后果？形成什么反馈回路？
- **机会成本**：选了它，我们就没在做什么？锁死了哪些资源？放弃了哪些选项？反悔的代价有多大？
- **反转 / Steelman**：把反方论点论证到最强，再回应它——不许打稻草人。

## 四、收尾必问

- **什么证据会让你改变主意？** 答不出来，说明这不是判断，而是立场。
- 结论必须落到三选一：**继续 / 修改 / 放弃**，并给出理由与下一步最小验证动作。
